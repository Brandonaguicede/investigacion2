ARQUITECTURA
Browser -> http://localhost:8081 -> auction-web (React compilado + Nginx)
Browser -> ws://localhost:8081/ws -> Nginx -> http://auction-server:8080/ws
auction-server -> Application -> Domain / Infrastructure
Servicios Compose: auction-server, auction-web.
Solo auction-web publica puerto: 8081:80.
auction-server expone 8080 solamente dentro de Docker.
ASPNETCORE_URLS=http://+:8080; HttpsRedirection__Enabled=false.
React construye /ws con window.location; http -> ws, https -> wss.
No hostname ni puerto hardcodeado en React.
GET /health responde 200 "OK"; no contiene logica de negocio.
Healthcheck de auction-web: wget a / y /health (proxy al backend).
depends_on solo establece orden; --wait espera el healthcheck integrado.
No se instalo ningun paquete de healthcheck en ASP.NET.
